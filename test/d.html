追求极致的用户体验

四种加密方案各司其职，覆盖从浏览器到操作系统、从个人到企业的全部解析场景。

DNS over HTTPS

DoH · RFC 8484

将 DNS 查询封装在 HTTPS 请求中，与正常网页流量完全混淆，有效绕过针对 53 端口的封锁与审查，隐私性最强。

立即配置 →

DNS over TLS

DoT · RFC 7858

通过专用 853 端口建立 TLS 加密隧道，协议开销更低、连接更稳定，是操作系统与路由器全局加密的首选方案。

立即配置 →

DNS over QUIC

DoQ · RFC 9250

基于 QUIC 协议的低延迟加密传输，结合 UDP 多路复用与 0‑RTT 特性，尤其适合移动端与高丢包网络环境。

立即配置 →

DNS over HTTP3

HTTP3 · RFC 9114

基于 HTTP/3 与 QUIC 协议的超高速加密 DNS 查询，利用 0‑RTT 连接恢复与多路复用，大幅降低解析延迟，尤其适合 5G 与高动态网络环境。

立即配置 →

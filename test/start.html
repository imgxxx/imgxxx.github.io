DNS over HTTPS

DoH · RFC 8484

将 DNS 查询封装在 HTTPS 请求中，与正常网页流量完全混淆，隐私性最强。

立即配置 →

DNS over TLS

DoT · RFC 7858

通过专用 853 端口建立 TLS 加密隧道，是操作系统与路由器全局加密首选。

立即配置 →

DNS over QUIC

DoQ · RFC 9250

基于 QUIC 协议的低延迟加密传输，适合移动端与高丢包网络环境。

立即配置 →

DNS over HTTP3

HTTP3 · RFC 9114
